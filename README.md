
Fake News Detection using NLP and Machine Learning

Project Overview

This project detects whether a news article is likely fake or genuine using Natural Language Processing (NLP) and Machine Learning.

Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Streamlit

Dataset

The model was trained using the Fake and Real News Dataset downloaded from Kaggle.

How to Run

1. Install the required Python packages.
2. Run "train_model.py" to train the model if needed.
3. Run "streamlit run app.py" to start the application.

Features

- Enter news text.
- Predict whether the news is likely fake or genuine.
- Display a model confidence score.
- Clear the entered text.

Note

Predictions are estimates and should not be treated as proof that a news article is true or false.
